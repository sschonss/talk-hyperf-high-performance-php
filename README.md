# High-Performance PHP com Hyperf — slides

**Slides (PT):** https://sschonss.github.io/talk-hyperf-high-performance-php/  
**Slides (EN):** https://sschonss.github.io/talk-hyperf-high-performance-php/en/  
**PDF (PT):** https://sschonss.github.io/talk-hyperf-high-performance-php/hyperf-high-performance-php.pdf  
**PDF (EN):** https://sschonss.github.io/talk-hyperf-high-performance-php/en/hyperf-high-performance-php.pdf

Deck em [Marp](https://marp.app) da palestra *Building High-Performance PHP Applications with Hyperf*,
reunindo "Acelerando Arquitetura de Microservices com PHP" e "Migração Eficiente: do Laravel para o Hyperf".

- `slides.md` — o deck em português (42 slides, em 3 partes). Cada slide tem pouco texto; o roteiro detalhado está nas **notas do apresentador** (`<!-- ... -->`).
- `slides.en.md` — the English translation (same 42 slides).
- `themes/aifa.css` — tema claro customizado.
- `assets/` — foto.

O deploy no GitHub Pages roda a cada push na `main` (`.github/workflows/pages.yml`).

## Comandos

```bash
npm run dev     # servidor com preview ao vivo
npm run build   # dist/index.html (modo apresentador: tecla P)
npm run pdf     # dist/hyperf-high-performance-php.pdf (com notas)
npm run pptx    # dist/hyperf-high-performance-php.pptx
```
